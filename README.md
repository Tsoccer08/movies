# Movie Recommendation Program

This project is a Java-based Movie Recommendation Program that allows users to view movies, search for movies by genre, save favorite movies, and load saved favorites from a file. The program was created to demonstrate Java programming concepts including classes, functions, conditionals, loops, collections, and file input/output.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code or another Java IDE.
3. Open a terminal inside the project folder.
4. Compile the program using:

   ```
   javac *.java
   ```
5. Run the program using:

   ```
   java Main
   ```

Instructions for using the software:

1. Start the program.
2. Select an option from the menu.
3. View all movies or search for movies by genre.
4. Add movies to your favorites list.
5. View saved favorite movies that are stored in the favorites.txt file.
6. Exit the program when finished.
